About

What this course is

This course teaches you to program an Arduino. It assumes you have never written code. Early labs run in Tinkercad Circuits so you can practice without a kit; optional hardware runs in parallel when you have a board.

It sits alongside The Arduino Ladder on the same hub. The Ladder is a project-and-electronics spine (nine builds). Arduino Coding is a sketch-and-patterns spine (modules). You can take either first, or both.

Two tracks in every module

Concepts — syntax, pins, sensors, buses, networking. Patterns — debounce, non-blocking millis(), state machines, interrupts, clean structure. You meet both as soon as the next project needs them.

Before you start

What you need

Software (required)

  • A free Tinkercad account for early labs
  • Arduino IDE 2.x (or Web Editor) from arduino.cc
  • A laptop or computer with a browser

Hardware (optional at first)

  • Arduino Uno (or compatible) and USB cable
  • Breadboard, LEDs, resistors, buttons — a starter kit covers Modules 0–6 well
  • ESP32 later, when the IoT module opens
