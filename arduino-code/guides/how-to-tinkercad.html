How to Tinkercad

Click-by-click Circuits setup and screenshot checklist.

Audience: First-time users. No screenshots required — match each step to what you see on screen. Official site: https://www.tinkercad.com/ → Circuits

Use this with Lesson 0.3. Electricity vocabulary: electricity primer.

Guide

Screenshot checklist (print or keep beside you)

Work top to bottom. Check each box when you can see it on your screen.

A. Account and Circuits home

  • [ ] Signed in to Tinkercad (Autodesk account)
  • [ ] Left navigation or top hub shows Circuits (not only 3D Design)
  • [ ] Circuits gallery / “Your circuits” view is open
  • [ ] Create new Circuit (or New Circuit) control is visible

B. Empty circuit workspace

  • [ ] Blank workplane (grid) in the center
  • [ ] Circuit title at top (click to rename) — set to e.g. M0-L03-FirstLed
  • [ ] Components panel (search box + categories) on the right or accessible via a “+ / Components” control
  • [ ] Code button visible (opens the code panel)
  • [ ] Start Simulation / play-style control visible (often top of workspace)

C. Parts placed

  • [ ] Arduino Uno R3 on the workplane
  • [ ] LED placed
  • [ ] Resistor placed — value shows 220 Ω (not 220 kΩ)
  • [ ] Optional: Breadboard small placed

D. Wiring and polarity

  • [ ] Wire: Uno digital pin 13 → one end of resistor
  • [ ] Wire: other end of resistor → LED anode (+)
  • [ ] Wire: LED cathode (−) → Uno GND
  • [ ] No direct 5V → LED with no resistor

E. Code Text mode

  • [ ] Code panel open
  • [ ] Dropdown set to Text (not Blocks)
  • [ ] Confirmed replace Blocks → Text if prompted
  • [ ] Starter sketch pasted; no red error banner blocking you

F. Simulation running

  • [ ] Clicked Start Simulation
  • [ ] UI shows simulation running (not paused) — see §7
  • [ ] LED behaves as the sketch says (on, or blinking in later lessons)
  • [ ] Optional: Serial Monitor area available inside the sim UI for later lessons

G. Save / duplicate habits

  • [ ] Circuit has a clear name (M0-…, M1-…)
  • [ ] You know where Duplicate / copy lives for a clean “before I break it” copy
  • [ ] You can find the circuit again under Circuits → your designs
Guide

1. Open Circuits (after login)

  1. Go to Tinkercad and Sign in.
  2. Open Circuits.

- If you land in 3D Designs, look for a mode switch, left sidebar, or “Circuits” in the product picker — Circuits is a separate area.

  1. Click Create new Circuit.

You should see an empty grid and a place to add components.

Guide

2. Rename the circuit

  1. Click the default title at the top (often “Circuit” or similar).
  2. Type a lesson-based name: M0-L03-FirstLed.
  3. Press Enter.

Good names make Module 1–3 folders of experiments findable later. See practice habits.

Guide

3. Find and place components

  1. Open the Components panel.
  2. Use the search box (faster than scrolling categories).
  3. Drag onto the workplane, one at a time:

- Arduino Uno R3 - LED - Resistor - Optional: Breadboard (small)

Rotate: select a part → use rotate handle or rotate key/button shown in the inspector until leads face a comfortable direction.

Delete: select part → Delete / Backspace.

Guide

4. Set the resistor to 220 Ω (not kΩ)

  1. Click the resistor.
  2. In the inspector, find resistance / value.
  3. Set 220.
  4. Set units to Ω (ohms).
WrongWhat happens
220 kΩAlmost no current → LED looks dead
220 mΩNonsensical for this lab — avoid

Lesson 0.3 allows 220 Ω, 330 Ω, or 1 kΩ — pick one and stick with it.

Guide

5. Identify LED anode and cathode in Tinkercad

  1. Click the LED.
  2. Open the inspector (properties for the selected component).
  3. Find which terminal is anode / cathode, or note polarity marks on the symbol.
  4. Remember the course rule:
pin → resistor → LED anode (+) → LED cathode (−) → GND

If the inspector is unclear: try one orientation; if the LED stays dark with a known-good digitalWrite(HIGH) sketch, flip the LED before rewriting code.

Real-world clues (for later hardware): longer lead ≈ anode; flat edge / shorter lead ≈ cathode. Details: electricity primer §4.

Guide

6. Wire the first LED circuit

Click a component terminal, then click the destination terminal to draw a wire (Tinkercad’s usual click-to-click wiring).

  1. Pin 13 on the Uno → first lead of the 220 Ω resistor.
  2. Other resistor lead → LED anode.
  3. LED cathode → Uno GND (any GND pin on the Uno drawing).

Color tip: many people use black or green for GND and another color for the signal wire — optional but readable.

Breadboard optional path: same electrical order; use one row for each junction; put GND on a − rail tied to Uno GND (getting started §7).

Guide

7. Code panel → Text mode

  1. Click Code.
  2. If you see puzzle-piece Blocks, open the language / mode dropdown.
  3. Choose Text.
  4. If asked to replace Blocks with a text sketch, confirm.
  5. Delete the template if the lesson says so; paste the lesson starter sketch.

This course is Text sketches, not Blocks. Staying on Blocks will fight every lesson.

Guide

8. Start Simulation vs paused

  1. Click Start Simulation (play-style control).
  2. Watch for running state:

- Running: time advances; LED can change; Serial (if used) can print. - Paused / stopped: circuit sits inert — easy to mistake for a wiring bug.

Simulation checklist (before blaming code):

  1. Simulation actually running?
  2. LED polarity correct?
  3. Resistor in series at 220 Ω?
  4. GND wire on GND, not 5V by mistake?
  5. pinMode / digitalWrite pin number matches the wire?

Then open troubleshooting FAQ if still dark.

Guide

9. Serial Monitor inside Tinkercad

When a lesson uses Serial.println:

  1. Start Simulation.
  2. Find Serial Monitor in the Code / simulation UI (often below or beside the code).
  3. Baud in the sketch should be the usual course value (9600 unless a lesson says otherwise).

Full skill page: how-to-serial-monitor.md.

11. What “done” looks like for Lesson 0.3

  • Uno + resistor + LED wired as pin → resistor → LED → GND
  • Resistor is 220 Ω
  • Code panel in Text mode
  • Simulation runs without error toast
  • LED lights for a HIGH starter (full Blink comes in 0.5)
