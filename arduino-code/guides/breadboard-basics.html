Breadboard basics

Rows vs rails, shared GND, mental model for Module 0–1 wiring.

Goal: Know which holes are connected before you place your first LED. Not a goal: Fancy multi-board layouts or proto-PCB design.

Read this when Lesson 0.3 mentions a breadboard, or before wiring several LEDs in Module 1. Pair with the electricity primer for voltage / GND / polarity.

Guide

1. What a breadboard is

A solderless breadboard is a plastic grid of holes with metal clips underneath. You push component legs and jumper wires into the holes. No soldering — move parts until the circuit works.

In Tinkercad, the on-screen breadboard follows the same connection rules as a real one. Learn the rules once; they transfer to a desk kit later.

Guide

2. The only rules that matter

Rows (the short strips)

On each half of the board, five holes in a row (often labeled a–e or f–j) share one metal clip.

a3  b3  c3  d3  e3   ← all connected to each other
  • Put a resistor leg in c3 and a wire in e3 → they touch electrically.
  • Different row numbers (3 vs 4) are not connected unless you add a jumper.

The center gap

The board is split down the middle.

a3 b3 c3 d3 e3   |gap|   f3 g3 h3 i3 j3
  • e3 does not connect across to f3.
  • That gap is where DIP chips sit (legs on each side). For beginner LED labs, treat halves as separate until you bridge them with a wire.

Power rails (the long strips)

Along the long edges you usually see + (red) and − / blue lines. Those holes connect along the length of the board (sometimes broken in the middle on longer boards — check continuity if a rail “dies” halfway).

Beginner habit:

  1. Uno 5V → + rail (once).
  2. Uno GND → − rail (once).
  3. Every LED cathode, button-to-GND, and sensor ground taps the − rail.
  4. Parts that need 5 V tap the + rail.

That is shared GND in practice: one return path idea for the whole project.

Guide

3. Picture: one LED on a breadboard

Same electrical path as “direct to the Uno,” just using rows and rails:

Uno pin 13 ──jumper──► row 3 (one end of 220 Ω)
                         other end of 220 Ω in row 5
                         LED anode in row 5
                         LED cathode in row 7
                         jumper from row 7 ──► GND (−) rail
Uno GND ─────────────────────────────────────► GND (−) rail

ASCII of the idea (ignore exact hole letters):

[pin 13] → [resistor] → [LED anode → cathode] → [GND rail] → Uno GND

Check understanding

Note

You plug the LED anode and one resistor leg into the same row. Are they connected? Yes — same row number on the same half = same clip. That is how “pin → resistor → LED” becomes physical.

Guide

4. Why Module 1 loves one GND rail

Three LEDs do not each need their own wire back to a different Uno GND pin. They can all return to the same − rail, and that rail has one jumper to Uno GND.

Pin 8  → R → LED → GND rail ─┐
Pin 9  → R → LED → GND rail ─┼─→ Uno GND
Pin 10 → R → LED → GND rail ─┘

If one LED stays dark, ask: is its cathode on the GND rail, and is that rail actually jumpered to Uno GND?

Bridging the center gap in your head“I wired it” but halves don’t meetAdd an explicit jumper across the gap if needed
Using adjacent row numbers thinking they’re linkedOpen circuit / dark LEDSame number on a–e (or f–j), or add a jumper
+ and − rails swappedWeird always-on / stress riskRed/+ to 5V, blue/− to GND — label once

7. Mini checklist before Start Simulation / Upload

  • [ ] Each series path is pin → resistor → LED anode → cathode → GND (or rail → Uno GND).
  • [ ] Shared returns meet on the GND (−) rail.
  • [ ] No accidental 5V-to-GND short on one row.
  • [ ] Resistors are 220 Ω, not 220 kΩ.
  • [ ] LED polarity: anode toward the pin/resistor; cathode toward GND.
