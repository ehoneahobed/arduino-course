Glossary

Plain-language terms: pin, sketch, GND, PWM, debounce, FSM, Serial, and more.

Use this page whenever a lesson drops a word you have not lived with yet. “Introduced in” means the first lesson where the idea is taught for real (not only mentioned).

Guide

A–B

ADC (Analog-to-Digital Converter) Hardware on the board that turns a smooth voltage (like from a potentiometer) into a whole number your sketch can read — on classic Uno analog pins, roughly 0–1023. Introduced in: Module 3 · Lesson 3.1–3.2

Anode The + side of an LED (current enters here in the simple story). In wiring diagrams it faces the pin/resistor side of the path. Introduced in: Module 0 · Lesson 0.3 · see also electricity primer

Arduino IDE The desktop app (or Web Editor) where you write sketches, click Verify, and later Upload to a real board. Introduced in: Module 0 · Lesson 0.2

Baud (baud rate) How fast Serial text is sent, in bits per second. The sketch (Serial.begin(9600)) and the Serial Monitor dropdown must match. Wrong baud → garbage characters. Introduced in: Serial Monitor how-to; reinforced Module 3 · 3.2

Blocking Code that stops everything else until it finishes — classic example: delay(1000) freezes the whole loop for one second. Introduced in: Module 2 · Lesson 2.1

Board The physical (or simulated) microcontroller circuit — e.g. Arduino Uno — with pins you can wire to. Introduced in: Module 0 · Lesson 0.1

Bounce (contact bounce) A mechanical button does not switch cleanly once; it chatters HIGH/LOW for a few milliseconds. Your sketch can see many “presses.” Introduced in: Module 1 · Lesson 1.4

Breadboard A plastic board with hidden metal strips so you can plug wires and parts without soldering. Rows share connections; edge rails are for power/GND. Introduced in: Getting started §7; used Module 0 · 0.3

BSP (Board Support Package) Extra software you install in the IDE so it knows a board family (for example ESP32). Introduced in: Module 8 · Lesson 8.1

Guide

C–D

Cathode The − side of an LED (current leaves toward GND in the simple story). Often the flatter edge / shorter lead on a real LED. Introduced in: Module 0 · Lesson 0.3

Compile / Verify The IDE checks your sketch for language errors and builds machine code. Verify does this without needing a board attached. Introduced in: Module 0 · Lesson 0.2

Current How much electric charge is flowing — think “flow rate.” Too much through an LED can destroy it; a resistor limits current. Introduced in: Electricity primer

Debounce Ignoring bounce so one physical press counts as one logical press (wait a short stable time, or similar). Introduced in: Module 1 · Lesson 1.5; non-blocking form Module 2 · 2.5

delay() Pauses the board for a number of milliseconds. Easy for Blink; harmful when you need buttons and LEDs to “listen” at the same time. Introduced in: Module 0 · Lesson 0.5; problems Module 2 · 2.1

Digital pin A pin that is mainly HIGH or LOW (on/off thinking), used with digitalRead / digitalWrite. Introduced in: Module 0 · Lesson 0.1 / 0.5

Duty cycle In PWM, the fraction of time the signal is ON within each cycle — higher duty ≈ brighter LED (on average). Introduced in: Module 3 · Lesson 3.3

Guide

E–G

Edge (rising / falling) A change from LOW→HIGH (rising) or HIGH→LOW (falling). Useful for “was just pressed” logic, not “is still held.” Introduced in: Module 1 · Lesson 1.4

Enum A way to name a small set of states (e.g. IDLE, RUNNING) instead of magic numbers. Common in state machines. Introduced in: Module 5 · Lesson 5.2

ESP32 A different microcontroller board with built-in Wi‑Fi (and more). Used in Module 8 — not required for Modules 0–3. Introduced in: Module 8 · Lesson 8.1

Event Something that happened (button edge, timer fired) that may cause a state change — as opposed to constantly re-checking levels. Introduced in: Module 5 · Lesson 5.4

FSM (Finite State Machine) A design where the program is in exactly one state at a time, and events cause transitions. Beats tangled if spaghetti for modes. Introduced in: Module 5 (preview language in Module 2); Lesson 5.1–5.2

GND (Ground) The 0 V reference and the return path for current. Almost every simple circuit needs a wire back to GND. “Shared GND” = everything returns to the same ground idea. Introduced in: Module 0 · Lesson 0.1; electricity primer

Guide

H–L

HIGH / LOW Digital levels your sketch writes or reads. On a 5 V Uno, HIGH is “about 5 V worth of on,” LOW is “about 0 V / grounded.” Exact volts are a physics detail — treat them as on/off labels first. Introduced in: Module 0 · Lesson 0.5

Hysteresis Using two thresholds (e.g. turn lamp on below 300, off above 400) so a noisy sensor does not flicker at one borderline value. Introduced in: Module 3 · Lesson 3.4

I²C (I2C) A two-wire communication style (clock + data) used by many displays and sensors. Devices share the bus and have addresses. Introduced in: Module 6–7 (display / scan lessons)

INPUT_PULLUP pinMode mode that enables an internal resistor pulling the pin toward HIGH when nothing presses it to GND. With a button to GND, pressed reads LOW. Introduced in: Module 1 · Lesson 1.3

ISR (Interrupt Service Routine) A short function that runs when a hardware interrupt fires (e.g. pin change). Advanced — keep ISRs tiny; Module 6 rules apply. Introduced in: Module 6 · Lesson 6.2

Library Reusable code someone else wrote that you #include (e.g. Servo). Installed via Library Manager on the IDE; support varies in Tinkercad. Introduced in: Module 4 · Lesson 4.1

Level The current HIGH or LOW value — “is the button held?” — vs an edge (“did it just change?”). Introduced in: Module 1 · Lesson 1.3–1.4

Guide

M–P

millis() Returns how many milliseconds since the board started (an always-counting “odometer”). Used for non-blocking timing: check whether enough time passed instead of freezing with delay. Introduced in: Module 2 · Lesson 2.2

MQTT A lightweight publish/subscribe messaging style used in IoT (topics, brokers). Module 8 territory. Introduced in: Module 8 · Lesson 8.4

Microcontroller A tiny computer on a chip: runs your sketch, talks to pins, repeats loop forever. Introduced in: Module 0 · Lesson 0.1

Non-blocking Design that keeps loop cycling so you can blink, read buttons, and time events together — usually with millis() timestamps. Introduced in: Module 2 · Lesson 2.1–2.2

Ohm (Ω) Unit of resistance. A 220 Ω resistor is very different from 220 kΩ (220,000 Ω) — always check the unit in Tinkercad. Introduced in: Module 0 · Lesson 0.3

Pin A numbered connection on the board where you attach wires (digital, analog, power, GND). Always use the same number in code and on the wire. Introduced in: Module 0 · Lesson 0.1

Potentiometer (pot) A knob that acts as an adjustable voltage divider — three legs: ends to 5V and GND, middle (wiper) to an analog pin. Great beginner stand-in for light sensors. Introduced in: Module 3 · Lesson 3.2 / 3.6

Pull-up / pull-down A resistor that gently forces a pin to a default HIGH (pull-up) or LOW (pull-down) when a button is not connecting it elsewhere. Introduced in: Module 1 · Lesson 1.3; electricity primer

PWM (Pulse Width Modulation) Faking “in-between” brightness or speed by switching HIGH/LOW very fast. On Uno, pins marked ~ support analogWrite PWM. Introduced in: Module 3 · Lesson 3.3 Note: analogWrite is not the inverse of analogRead — different jobs.

Guide

R–S

Resistance / resistor Opposition to current. A series resistor with an LED limits current so the LED (and pin) stay safe. Introduced in: Module 0 · Lesson 0.3; electricity primer

Serial A text channel between your sketch and the computer (or Tinkercad’s Serial Monitor). Use Serial.println(...) to print debug values. Introduced in: how-to-serial-monitor.md; Module 1+; required Module 3 · 3.2

Sketch Your Arduino program — usually one .ino file with setup() and loop(). Introduced in: Module 0 · Lesson 0.1 / 0.4

SPI Another wired communication style (faster, more wires than I²C). Light touch in Module 7 — skip without guilt if overloaded. Introduced in: Module 7 · Lesson 7.4

State “Which mode am I in right now?” (idle, waiting, alarm…). Core FSM idea. Introduced in: Module 5 · Lesson 5.1

Guide

T–V

Tinkercad Circuits Browser simulator for Arduino + common parts. Primary early-lab environment for this course. Introduced in: Module 0 · Lesson 0.3; how-to-tinkercad.md

[TC†] Lesson marker: Tinkercad is incomplete or misleading for this topic (bounce cleanliness, some sensors, Wi‑Fi, etc.). Introduced in: throughout; habits in practice guide

Upload Send a compiled sketch to a real board over USB. Different from Verify and from Tinkercad’s Start Simulation. Introduced in: Module 0 · Lesson 0.2; checklist Module 7 · 7.1

volatile A keyword telling the compiler a variable can change outside normal loop flow (e.g. in an ISR). Advanced Module 6 topic. Introduced in: Module 6 · Lesson 6.3

Voltage Electrical “pressure” difference — think water pressure. Uno logic is commonly 5 V; many ESP32 pins are 3.3 V (do not mix carelessly). Introduced in: electricity primer

Voltage divider Two resistances in series across a voltage; the middle point is a voltage in between. Used with LDRs and explained for night-light wiring. Introduced in: electricity primer preview; Module 3 · Lesson 3.6
