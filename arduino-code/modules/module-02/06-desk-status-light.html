Build: Desk status light

Spine build: a desk status light with OFF / FOCUS / BREAK modes — non-blocking pulse, debounce, optional chirp. Gate A: no delay() on the interactive path.

About 55 minutes.

Start here

Learning outcomes

  1. Build idle pulse + button-cycled modes using only non-blocking timing.
  2. Combine repeating timers, mode state, and millis debounce.
  3. Meet Gate A: LEDs and button stay cooperative.
Brief

Modes

ModeLED
OFFSolid off
FOCUSSlow pulse (~800 ms)
BREAKFast pulse (~200 ms)

Debounced button cycles OFF → FOCUS → BREAK → OFF. Optional ~120 ms chirp on change. Zero delay() in loop.

Wire

Suggested pins

Circuit M2-L06-DeskStatus: status LED pin 9, button 2 (INPUT_PULLUP), optional piezo 11.

OFF --press--> FOCUS --press--> BREAK --press--> OFF
Build

Complete shape

25 min

Mode cycle + millis pulse

unsigned long intervalForMode(int m) {
  if (m == MODE_FOCUS) return 800;
  if (m == MODE_BREAK) return 200;
  return 0;
}
// on debounced press: mode++; wrap; reset prevBlink; LED LOW; arm beep
// if mode == OFF: force LOW
// else: heartbeat with intervalForMode(mode)
// expire one-shot beep with millis

Build order: heartbeat → mode variable → debounced cycle → per-mode intervals → optional beep → header docs.

Deliverable

Rubric

  • All three modes work
  • One press → one mode step
  • No delay / blocking while in loop
  • Debounce present
  • Header lists pins + behavior
Patterns

Stack

Pattern

Millis heartbeat · non-blocking debounce · optional one-shot chirp. Forbidden: delay() and blocking wait-for-release on the interactive path.

Check

Check yourself

  1. What are the three modes and how does the button move between them?
    Model answer

    OFF → FOCUS → BREAK → OFF on each accepted press.

  2. Why reset prevBlink and force LED LOW on mode change?
    Model answer

    So the new rate starts cleanly and you do not inherit a bright LED into OFF.

  3. Which Module 2 patterns appear in the complete sketch?
    Model answer

    Heartbeat millis timer, non-blocking debounce, optional one-shot beep.

  4. Does this sketch use delay()?
