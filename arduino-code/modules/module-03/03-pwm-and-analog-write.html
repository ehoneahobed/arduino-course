PWM & analogWrite

PWM duty cycle makes LEDs look dimmer or brighter. Map a pot reading to analogWrite on a ~ pin.

About 40 minutes.

Picture

Duty cycle is not steady volts

At duty 64 (~25%), the pin is mostly LOW with short HIGH pulses — not a steady 1.25 V. Your eye averages the blink into “dim.” Terms: glossary (PWM / duty). Map 0…1023 → 0…255 before analogWrite — different scales.

Start here

Learning outcomes

  1. Explain PWM as rapid on/off whose duty cycle changes perceived brightness.
  2. Use analogWrite(pin, 0…255) on a PWM-capable pin.
  3. Map pot → ADC → map → analogWrite.
Concept

Duty cycle, not true analog voltage

Concept

analogWrite uses PWM: the pin flips HIGH/LOW fast. 0 = off, 255 ≈ full on, 128 ≈ half — your eye averages the pulses.

Part

Which pins?

Uno PWM pins: 3, 5, 6, 9, 10, 11 (marked ~). Not A0 — that is an ADC input.

analogWrite(ledPin, 0);    // off
analogWrite(ledPin, 255);  // full
analogWrite(ledPin, 64);   // dim
Lab

Dim with a knob

15 min

Circuit M3-L03-PwmDim: pot on A0; LED on pin 9 (~) via 220 Ω.

Complete shape

void loop() {
  int raw = analogRead(potPin);
  int duty = map(raw, 0, 1023, 0, 255);
  analogWrite(ledPin, duty);
}

Fan-speed metaphor: same pattern as “how hard am I driving the load.” Real motors need drivers later.

Patterns

Map then write

Pattern

raw = analogRead → duty = map(…, 0, 255) → analogWrite(pwmPin, duty). Named const int for the PWM pin.

Check

Check yourself

  1. What does duty cycle mean for an LED?
    Model answer

    Fraction of time the pin is HIGH; higher duty → brighter average.

  2. Best pin for dimming an LED with analogWrite?
  3. What range does analogWrite expect?
    Model answer

    0–255 duty.

  4. analogWrite(A0, 128) is the right way to dim from a pot pin.
