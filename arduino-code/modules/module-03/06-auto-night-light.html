Build: Auto night-light

Spine build: an auto night-light — sense light, decide with hysteresis and/or PWM glow, act on an LED. Serial is how you tune.

About 55 minutes. Path A (threshold), B (PWM), or both.

Start here

Learning outcomes

  1. Drive an LED from an LDR (or pot) with hysteresis and/or mapped PWM.
  2. Combine Serial debug, optional rolling average, and Module 2–friendly timing.
  3. Document wiring and thresholds for tuning.
Brief

Paths

PathBehavior
A — ThresholdLED fully on when dark (hysteresis); off when bright
B — PWM glowBrightness rises as light falls (inverted map)
A+B stretchOff when bright; when dark, PWM ∝ how dark

Done: cover sensor → lamp responds; uncover → clean release; Serial alone can tune; header documents wiring.

Wire

Tinkercad

Circuit M3-L06-NightLight. Pot stand-in: 5V — wiper→A0 — GND; LED on 9 (~). Or LDR divider:

5V ── LDR ──●── 10 kΩ ── GND
            │
           A0

Measure dark/bright with Serial before choosing thresholds — never guess.

Build

Logic shapes

25 min

Path A hysteresis / Path B PWM

// A
if (!lampOn && smooth < onBelow)  lampOn = true;
if (lampOn  && smooth > offAbove) lampOn = false;

// B — darker (lower raw) → brighter
int duty = constrain(map(smooth, 0, 1023, 255, 0), 0, 255);
analogWrite(ledPin, duty);

Optional: Lesson 3.5 average into smooth. Pace Serial with a millis timer.

Deliverable

Checklist

  • Dark → lamp responds; bright → releases without chatter
  • Named pins and thresholds at top
  • Serial shows raw (and smooth if used) + state/duty
  • Header documents wiring and polarity
  • No long interactive delay if you add buttons later
Patterns

Stack

Pattern

Serial stream · hysteresis and/or mapped PWM · optional rolling average · named constants. Sense → decide → act with continuous values.

Check

Check yourself

  1. Why measure with Serial before setting thresholds?
    Model answer

    So onBelow/offAbove match real dark/bright numbers for your wiring.

  2. What does inverted map(..., 255, 0) do for a night-light?
    Model answer

    Lower (darker) readings become higher PWM duty — brighter LED.

  3. Which Module 3 patterns appear in this build?
    Model answer

    analogRead, Serial, map/PWM and/or hysteresis, optional array average.

  4. A potentiometer stand-in is allowed if you lack an LDR in the sim.
