Analog vs digital pins

Digital is on/off. Analog input measures voltage in many steps — on a Uno, about 0–1023 on pins A0–A5.

About 35 minutes. Wire a pot; full streaming arrives in 3.2.

Start here

Learning outcomes

  1. Explain digital (HIGH/LOW) vs analog (many steps) on an Uno.
  2. State the ADC idea: ~10-bit readings 0–1023 on A0–A5.
  3. Wire a potentiometer to an analog input in Tinkercad.
Concept

ADC turns voltage into a number

Concept

A digital pin is a switch. An analog input measures voltage with an ADC. On a classic Uno: integers 0 (near 0 V) through 1023 (near 5 V).

0 V  --------------------  5 V
0    256   512   768   1023
Part

Three kinds of “pins”

KindLabelsAPIValues
Digital I/O0–13digitalRead / WriteHIGH/LOW
Analog inputA0–A5analogRead0–1023
PWM outputpins with ~analogWrite0–255 duty (3.3)

analogWrite is not the opposite of analogRead. Different hardware, different ranges.

Wire

Potentiometer (3 pins)

5V ──► outer leg A
         middle (wiper) ──► A0
GND ──► outer leg B

Middle pin must go to an analog input. Swap outer legs and the knob direction reverses.

Lab

Place a pot

12 min

Circuit M3-L01-AnalogPins: pot 5V — wiper→A0 — GND. Optional smoke-test: Serial.println(analogRead(A0)); — numbers should move ~0–1023.

Patterns

Name analog pins

Pattern

Use const int potPin = A0; and treat the reading as data, not on/off.

Check

Check yourself

  1. What does the Uno ADC roughly return for 0 V and for ~5 V?
    Model answer

    About 0 and about 1023.

  2. Which pins are for analogRead on a Uno?
  3. analogWrite is simply the reverse of analogRead.
  4. Where does the pot wiper go?
    Model answer

    To an analog input such as A0; ends to 5V and GND.
