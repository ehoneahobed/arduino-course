I²C display hello world

Two wires — SDA and SCL — plus power and ground. A library turns pixels into print-style calls. Serial remains a valid stand-in when glass/libs are unavailable.

About 45 minutes (+ library install / first wiring).

Start here

Learning outcomes

  1. Wire an I²C display (SSD1306 OLED or 16×2 LCD) to Uno SDA/SCL.
  2. Install a library, show text, and update a live value without long delay.
  3. Explain TC† limits and why Serial stand-in is valid when needed.

Bus + address

Concept

SSD1306 often 0x3C/0x3D; LCD backpacks often 0x27/0x3F. Module 7 deepens scanning — today: match the Example address and verify power (some OLED are 3.3 V only).

Patterns

Library hello world first

Pattern

Install → Example → change only address → then merge. Thin wrappers (showStatus) so 6.6 can swap OLED/LCD/Serial.

Check

Check yourself

  1. Which two Uno pins are classic I²C SDA and SCL?
    Model answer

    A4 (SDA) and A5 (SCL) on classic Uno.

  2. Why might an SSD1306 stay blank with “correct” code?
    Model answer

    Wrong address, power (3.3 vs 5 V), wiring, or begin failure.

  3. What pattern keeps display code swappable with Serial?
    Model answer

    Thin wrappers (showCount) + optional USE_SERIAL_UI.

  4. Updating the OLED with delay(1000) between frames is fine for interactive sketches.
