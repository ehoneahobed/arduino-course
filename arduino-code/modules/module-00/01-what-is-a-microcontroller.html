What is a microcontroller?

Board, sketch, and upload — then a short pin hunt in Tinkercad. No wiring and no coding yet.

About 25 minutes. You do not need a physical board for this lesson.

Start here

Learning outcomes

By the end of this lesson you will be able to:

  1. Explain the difference between a board, a sketch, and upload (or simulate).
  2. Point to power, ground, and numbered digital pins on an Arduino Uno diagram and on a Tinkercad Arduino.
  3. Describe, in plain language, what a microcontroller does in a simple gadget (sense → decide → act).

Tools

  • Tinkercad Circuits — open a blank circuit and drop an Arduino Uno so you can click pins
  • Browser — optional Arduino Uno pinout PDF
  • Real Uno (optional) — same pin hunt on the silk-screen labels

You do not need to wire an LED yet. That starts later in Module 0.

Concept

What a microcontroller is

5 min
Concept

A microcontroller is a tiny computer on a chip. It reads inputs (buttons, sensors), runs your program, and drives outputs (LEDs, motors, buzzers). An Arduino Uno is a board: the chip plus USB, power regulation, and easy pin headers so beginners can plug in wires without soldering.

It is not a full laptop. No keyboard, no big screen, tiny memory. It is not magic. If an LED does not light later, the cause is almost always wiring, pin number, or code — and you will learn to check those in order.

Tinkercad’s Arduino is a model of a real Uno. For Module 0 that model is excellent; later modules will note where simulation differs from hardware.

Part 1

Three words you will use every day

5 min
WordEveryday meaning
BoardThe physical (or simulated) Arduino you see: PCB with a USB port and rows of metal pins.
SketchYour program — the .ino file with setup() and loop(). Arduino people say “sketch” instead of “app.”
UploadCopying the compiled sketch into the board’s memory so it runs even after you unplug USB. In Tinkercad you Start Simulation instead — same idea, no cable.
  1. You write a sketch (instructions).
  2. The computer compiles it (translates to machine code).
  3. You upload (or simulate) so the microcontroller runs those instructions forever in a loop.
Part 2

Sense → decide → act

3 min

Almost every project in this course follows the same story:

  1. Sense — read a pin (button pressed? light dark?).
  2. Decide — run your logic (if, timers, state machines later).
  3. Act — write a pin (LED on, servo move, send a message).

Module 0 mostly does the act part: turn an LED on and off. Sensing arrives in Module 1.

Part 3

Meet the Uno pin layout

5 min

On an Arduino Uno (and the Tinkercad copy), find these landmarks:

LabelWhat it isWhy you care
USBConnection to your computerPower + upload on real boards
5VFive-volt power pinFeeds many beginner sensors
GNDGround (0 V reference)Every circuit needs a shared ground
Digital 0–13Pins that are HIGH (~5 V) or LOW (0 V)LEDs, buttons, buzzers
~ on some pinsPWM-capable pinsDimming LEDs later (Module 3)
A0–A5Analog input pinsKnobs and light sensors later
Pin 13Often tied to an on-board LEDBuilt-in blink without external parts

Pin 13 tip: On a real Uno, a tiny LED near the board edge often mirrors pin 13. In Tinkercad you usually add an external LED so the blink is obvious.

The big rectangular chip in the middle of the Uno is the ATmega328P microcontroller. The rest of the board makes it easy to power, program, and wire.

Lab

Pin hunt in Tinkercad

8 min
  1. Go to Tinkercad and sign in (free account).
  2. Open Circuits → Create new Circuit.
  3. From the components panel, search Arduino Uno and drag it onto the workplane.
  4. Click the board. Hover or click pins until you can find:
    • 5V and at least one GND
    • Digital pins 8–13
    • Analog pins A0 and A1
  5. Optional: open the Arduino Uno pinout in another tab and match three pins by name.

You are done when you can say out loud: “Pin 13 is a digital pin; GND is ground; 5V is power.”

Patterns

Preview

Pattern (preview)

Later we will name pins with const int ledPin = 13; instead of sprinkling bare 13s through the code. Naming is a pattern for clarity. You will start using it when Blink arrives later in Module 0.

Check

Check yourself

  1. In one sentence each, what is a board, a sketch, and upload?
    Model answer

    Board = the hardware or simulation you see; sketch = your program; upload = put the program on the board (or Start Simulation in Tinkercad).

  2. Why does every LED circuit need a connection to GND?
    Model answer

    Ground completes the circuit — current needs a return path.

  3. Is pin A0 the same kind of pin as digital 13?
  4. True or false: Tinkercad’s “Start Simulation” is the learning stand-in for uploading to a real board in Module 0.
Watch outs

Common mistakes

MistakeFix
Confusing the USB cable with the programThe cable only carries power/data; the sketch is the instructions.
Looking for “the computer” inside TinkercadThe Arduino is the computer for your circuit.
Assuming pin numbers are arbitrary foreverPin numbers must match your wiring. Change either code or wires — keep them paired.
Skipping the pin huntFive minutes now saves confusion when Blink “does nothing” later.
Stretch (optional)

Sketch on paper a tiny gadget: a plant light that turns on when a room is dark. Label boxes for Sense, Decide, and Act. Keep the sketch; a later module will build something similar.
