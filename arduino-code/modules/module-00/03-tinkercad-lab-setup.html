Arduino Coding  ·  Module 0  ·  Lesson 0.3  ·  TC

Tinkercad Circuits lab setup

Build a safe LED circuit in Tinkercad: Uno, 220 Ω resistor, LED, Text code, and Start Simulation.

About 35 minutes. This lesson’s job is wiring + sim runs — a full blink arrives in Lesson 0.5.

Start here

Learning outcomes

  1. Create a Tinkercad Circuits project and place an Arduino Uno, LED, and resistor.
  2. Wire a safe LED circuit (pin → resistor → LED → GND) and explain why the resistor matters.
  3. Open the Code panel in Text mode and Start Simulation without errors.
Concept

Current must be limited

Concept

An LED only lights when current flows through it in the correct direction, and that current must be limited by a resistor. Too much current can destroy a real LED. Simulation is forgiving; good habits still matter.

Part 1

Create the circuit workspace

8 min
  1. Sign in to Tinkercad → Circuits → Create new Circuit.
  2. Rename the circuit to M0-L03-FirstLed.
  3. Drag: Arduino Uno R3, optional small breadboard, LED, Resistor.
  4. Click the resistor and set resistance to 220 Ω.
Part 2

Wire the standard blink circuit

12 min
Arduino digital pin 13  →  resistor  →  LED anode (+)  →  LED cathode (−)  →  GND
  1. Wire Uno pin 13 to one end of the 220 Ω resistor.
  2. Other end of the resistor to the LED anode.
  3. LED cathode to Uno GND.
  4. Double-check: no wire from 5V straight into the LED without a resistor.

Why pin 13? It is the classic Blink pin. You will change pins in Lessons 0.5–0.6.

Check this before you blame the code
  • Resistor in series (not bypassed)
  • LED anode toward the resistor / pin side; cathode toward GND
  • GND wire actually on GND
  • Same pin number in the wire and in the sketch

Click-path screenshots: How to Tinkercad. Dark LED playbook: Troubleshooting FAQ.

Part 3

Code panel and simulation

10 min
  1. Click Code → choose Text mode (not Blocks).
  2. Paste the starter sketch below.
  3. Click Start Simulation.

What you should see: the LED turns on and stays on (steady light proves the circuit).

Simulation checklist (before you blame the code)

  1. Is simulation actually running (not paused)?
  2. Is the LED oriented correctly?
  3. Is the resistor in series in the path?
  4. Is ground on GND, not 5V?
  5. Do pinMode / digitalWrite use the same pin as your wire?
Patterns

One change at a time

Pattern

Change one thing at a time. First get a steady ON. Then blink. Then change pin. Then change timing.

Starter sketch — LED stays ON

/*
 * Lesson 0.3 — Tinkercad lab setup STARTER
 * Circuit: pin 13 → 220Ω → LED → GND
 */

void setup() {
  pinMode(13, OUTPUT);
  digitalWrite(13, HIGH); // HIGH ≈ 5 V on Uno → LED on
}

void loop() {
  // Nothing yet — steady light proves the circuit.
}

Complete sketch — named pin preview

const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
  digitalWrite(ledPin, HIGH);
}

void loop() {
  // Still steady — blinking arrives in Lesson 0.5
}
Check

Check yourself

  1. Why put a resistor in series with the LED?
    Model answer

    Limit current; protect LED and pin.

  2. Which LED side should face GND?
  3. If the LED never lights but the sketch Verifies, what first?
  4. Draw from memory: pin → ? → LED → ?
    Model answer

    pin → resistor → LED → GND.

Watch outs

Common mistakes

MistakeWhat you seeFix
LED backwardsDark LEDFlip LED
No resistor (hardware)Dim/dead LED riskAlways add 220 Ω–1 kΩ
Wire to 5V instead of pin 13Always on, ignores codeDrive from the digital pin in code
Resistor 220 kΩ by typoVery dimUse 220 Ω
Stretch (optional)

Add a second LED on pin 12 with its own 220 Ω to GND. Modify the sketch so both stay on. Save as M0-L03-TwoLeds.
