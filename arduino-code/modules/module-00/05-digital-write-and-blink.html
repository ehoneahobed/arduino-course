Digital write & Blink

digitalWrite, delay, named pins, and your first visible blink — then change pin and rate on purpose.

About 35 minutes. Reuse the Lesson 0.3 LED circuit.

Start here

Learning outcomes

  1. Use digitalWrite with HIGH / LOW to control an LED.
  2. Use delay to create a visible blink (and know we will outgrow it).
  3. Change the pin number and blink rate, matching wires to code.
Concept

HIGH, LOW, and delay

Concept

A digital output pin has two main software levels: HIGH (~5 V on a classic Uno) and LOW (0 V). delay(milliseconds) pauses the board — simple for Blink, but it blocks all other work. Module 2 replaces most delay use with millis().

Part 1

The classic Blink pattern

8 min
  1. Turn LED on.
  2. Wait a bit.
  3. Turn LED off.
  4. Wait a bit.
  5. Repeat forever (loop).
digitalWrite(ledPin, HIGH);
delay(1000);              // 1000 ms = 1 second
digitalWrite(ledPin, LOW);
delay(1000);
Part 2

Named pins

Avoid magic numbers scattered everywhere. Prefer:

const int ledPin = 13;
pinMode(ledPin, OUTPUT);
digitalWrite(ledPin, HIGH);

Change the number in one place when you move the wire.

Lab

Tinkercad steps

15 min
  1. Duplicate your LED circuit; name it M0-L05-Blink.
  2. Paste the starter; Start Simulation — 1 s on / 1 s off.
  3. Change both delays to 200 — faster blink.
  4. Change ledPin to 8 and move the wire from 13 to 8.

Success: LED rhythm matches your delays; moving the pin works only when code and wire agree.

Starter sketch

const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(1000);
  digitalWrite(ledPin, LOW);
  delay(1000);
}

Complete sketch — named timings

const int ledPin = 13;
const int onMs   = 500;
const int offMs  = 500;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH);
  delay(onMs);
  digitalWrite(ledPin, LOW);
  delay(offMs);
}
Patterns

One source of truth

Pattern

One source of truth for pin numbers — const int ledPin at the top. Blink-with-delay is a teaching pattern; retire it for multi-task projects after Module 2.

Check

Check yourself

  1. What two arguments does digitalWrite need?
    Model answer

    Pin number and HIGH or LOW.

  2. delay(250) pauses for how many seconds?
  3. You change ledPin to 8 but leave the wire on 13. What happens?
    Model answer

    The LED on 13 stays dark (pin 8 wiggles with nothing attached).

  4. Why will we eventually stop using delay for big projects?
    Model answer

    It blocks the board from doing other work (buttons, extra LEDs, network later).

Watch outs

Common mistakes

MistakeSymptomFix
Forgot pinMode(..., OUTPUT)No controlAdd it in setup
Only one delay (no off)Looks always onNeed HIGH and LOW with delays
Delays of 1 or 2Looks steadyUse hundreds of ms
Wire/code pin mismatch“Code is broken!”Match them
Stretch (optional)

Heartbeat: on 100 ms, off 100 ms, on 100 ms, off 700 ms, repeat. Save as M0-L05-Heartbeat.
