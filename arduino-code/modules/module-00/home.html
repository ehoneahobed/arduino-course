Setup & First Light

Install tools, blink an LED, and understand sketch structure (setup / loop). Practice path: Tinkercad primary · hardware optional.

About 3–3.5 hours at a beginner pace. Project spine ends with a custom blink signature. New here? Read Getting started first. Stuck? Run the Debugging playbook (sim → wiring → pins → Verify → Serial → logic) before rewriting a sketch.
