Power, ground, and smoke-free habits

Shared GND is non-negotiable. GPIO is a signal pin — not a motor supply. Read 5V / 3.3V labels before plugging in.

About 40 minutes. Smoke prevention is a desk skill.

Start here

Learning outcomes

  1. Explain common ground, 5 V vs 3.3 V rails, and GPIO current limits.
  2. List smoke-free rules: no motors from GPIO; check module voltage; use drivers.
  3. Run a short lab that reinforces LED current awareness and shared GND.
Concept

Rails and loops

Concept

Uno GPIO is roughly 20 mA absolute-max (design closer to ~10 mA). A stalling motor at hundreds of mA will smoke a pin. Logic level ≠ power capability.

[Uno GND] ----+---- [Sensor GND]
              +---- [Display GND]
              +---- [External PSU GND]  // motors

Part

Smoke-free rules

  1. Resistor in series with bare LEDs
  2. Common GND for every module that shares signals
  3. Read Vcc on the module before connecting 5 V
  4. Never power motors/high loads from a GPIO pin
  5. Signal ≠ power — separate wires for heavy current
  6. Power off before major rewiring
  7. Smell hot / pin dies → stop, unplug, inspect
Lab

Power habits

15 min

Project M7-L02-PowerHabits: LED→9 via 220 Ω. Starter prints checklist. Complete: Serial confirm (g) after verifying GND continuity to a module rail. Write three rules in the header.

Patterns

Budget on paper first

Pattern

List each module’s Vcc and typical current vs USB (~500 mA). External supply → common GND. Label before plug.

Check

Check yourself

  1. What if a sensor shares SDA/SCL but not GND?
    Model answer

    Unreliable communication — fix a common GND.

  2. Why is a bare DC motor on pin 3 a bad idea?
    Model answer

    Stall current exceeds GPIO limits → heat/damage; use a driver + proper supply.

  3. Name two rails and one caution for each.
    Model answer

    Example: 5V — don’t feed 3.3 V-only parts; GND — must be common; 3.3V — limited current.

  4. A relay module with an onboard transistor is usually safer than a bare coil on GPIO.
