Why ESP32 after fundamentals

You already ship local stations. ESP32 adds radio, RAM, and 3.3 V GPIO. Prove blink + Serial on new silicon before joining Wi‑Fi.

About 40 minutes. Desk ESP32 only — Tinkercad is not the path.

Start here

Learning outcomes

  1. Contrast Uno-class AVR vs ESP32: Wi‑Fi, dual core, 3.3 V logic, pin caveats.
  2. Install the Espressif ESP32 board package, select a DevKit, upload blink / Serial banner.
  3. Explain why I/O, millis, FSM, and hygiene came before networking — and where future esp32/ fits.
Concept

Same sketch shape, new silicon

Concept

Uno is excellent for digital/analog I/O — no onboard Wi‑Fi. ESP32 adds radio, more RAM/Flash, often two cores, and 3.3 V GPIO. Module 7 voltage habits still apply. Module 8 is a bridge inside Arduino Coding, not the planned sibling esp32/ catalogue card.

Part

Board package checklist

  1. Arduino IDE → Boards Manager
  2. Search esp32 → install esp32 by Espressif Systems
  3. Tools → Board → your DevKit (e.g. ESP32 Dev Module)
  4. Plug USB → Tools → Port → new COM/tty
  5. Optional: Upload Speed 115200 if long cables fail

Prefer general-purpose GPIOs; avoid strapping pins for casual buttons; onboard LED pin varies — verify your board (often GPIO 2).

Lab

ESP32 hello

20 min

Project M8-L01-Esp32Hello. Install BSP; Board + Port; upload starter → Serial banner; move to complete (non-blocking blink + banner). Comment three Uno-vs-ESP32 wiring differences.

Patterns

Fundamentals before RF

Pattern

Prove blink + Serial on the ESP32 before joining Wi‑Fi. Same upload checklist discipline as Lesson 7.1 — new silicon. Assume 3.3 V logic unless a sheet says otherwise.

Check

Check yourself

  1. Name two hardware reasons ESP32 differs from Uno for this course.
    Model answer

    Any two: Wi‑Fi, 3.3 V logic, dual core / more RAM, different pins.

  2. What IDE feature installs ESP32 support?
    Model answer

    Boards Manager (esp32 by Espressif Systems).

  3. Why did the syllabus put Wi‑Fi after Modules 0–7?
    Model answer

    Need I/O, non-blocking, FSM, and hardware hygiene before RF complexity.

  4. Module 8 should replace the planned esp32/ catalogue card.
