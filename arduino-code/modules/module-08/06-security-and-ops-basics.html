Security & ops basics

Ops basics for Gate D: don’t leak passwords, don’t flood brokers, don’t leave actuators undefined when the network dies. Full TLS / OTA → future esp32/ course.

About 40 minutes. Extend 8.2 / 8.4 / 8.5 on the desk.

Start here

Learning outcomes

  1. Separate secrets/config from sketch logic; know what must never be committed.
  2. Apply simple rate limits on publish/POST.
  3. Define a fail-safe offline mode for one actuator.
Concept

Config vs code

Concept

Security at Module 8 depth: don’t leak passwords, don’t expose raw command topics for real locks, don’t leave actuators undefined when RF dies. Rate limits protect you and shared brokers.

FileCommit?Contents
secrets.hNoSSID, passwords, tokens
secrets.h.exampleYesPlaceholders only
config.h (optional)Yes if non-secretIntervals, topic prefix, pins
.inoYesFSM, sampling — no raw passwords
Part

Rate limits & fail-safe

Starting intervals: MQTT telemetry 5–30 s; HTTP POST 10–60 s. Enforce minPublishMs. On enter offline / reconnect wait: digitalWrite(actuator, SAFE_LEVEL). Document SAFE_LEVEL in the header. Unique DEVICE_ID on public brokers; no home security / PII on plaintext.

Lab

Ops hygiene demo

25 min

Project M8-L06-OpsBasics (or extend 8.5). Audit passwords into secrets.h; enforce minPublishMs; implement applyFailSafe() when leaving ONLINE; pull Wi‑Fi and confirm actuator goes safe while samples continue.

Patterns

Least surprise

Pattern

Config vs code. Minimum publish interval. Offline policy function. Ignore malformed MQTT/HTTP payloads — don’t toggle on garbage.

Check

Check yourself

  1. Name two items that belong in secrets.h, not the committed .ino.
    Model answer

    e.g. Wi‑Fi password, webhook token / broker password.

  2. What is a fail-safe for a heater relay when MQTT drops?
    Model answer

    Drive relay to safe OFF (de-energize).

  3. Why rate-limit publishes on a classroom public broker?
    Model answer

    Avoid flooding, bans, and useless battery/CPU use.

  4. Module 8 replaces the need for the future esp32/ security curriculum.
