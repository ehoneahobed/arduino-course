Functions that do one job

Extract helpers like allLedsOff() and setTraffic(state) so each function does one job and loop stays readable.

About 40 minutes. Prepares the Lesson 1.8 spine build.

Start here

Learning outcomes

  1. Extract helpers like allLedsOff() and setTraffic(state).
  2. Pass pin arguments into functions.
  3. Read a sketch: constants → setup → loop → helpers.
Concept

Named blocks you call

Concept

You already call digitalWrite and delay. Your own functions keep loop short. One job per function beats a 100-line mega-loop.

Part

allLedsOff, setTraffic, pulsePin

void allLedsOff() {
  digitalWrite(redPin, LOW);
  digitalWrite(yellowPin, LOW);
  digitalWrite(greenPin, LOW);
}

void setTraffic(int state) {
  allLedsOff();
  if (state == 0) digitalWrite(redPin, HIGH);
  else if (state == 1) digitalWrite(yellowPin, HIGH);
  else if (state == 2) digitalWrite(greenPin, HIGH);
}

void pulsePin(int pin, int onMs) {
  digitalWrite(pin, HIGH); delay(onMs); digitalWrite(pin, LOW);
}

Prefer letting loop own timing — helpers stay reusable.

Lab

Thin loop

15 min

Circuit M1-L07-Functions. Drive red → yellow → green only by calling helpers from loop.

loop as a story

void loop() {
  setTraffic(0); delay(1200);
  setTraffic(1); delay(400);
  setTraffic(2); delay(1200);
  for (int i = 0; i < 3; i++) {
    pulsePin(yellowPin, 120); delay(120);
  }
}
Patterns

One job

Pattern

allLedsOff does not read buttons. setTraffic does not debounce. Small functions compose into appliances.

Check

Check yourself

  1. What does void mean in void allLedsOff()?
    Model answer

    The function returns no value.

  2. Why pass int pin into pulsePin?
    Model answer

    So one helper can pulse any pin you pass.

  3. Should setTraffic call delay?
  4. Where do helpers usually live relative to loop?
    Model answer

    Often below loop (or above setup); stay consistent.

Watch outs

Common mistakes

MistakeFix
Empty helper bodyFill in the writes
Mega-function that does everythingSplit into one-job helpers
Declaring helpers inside loopKeep them at file scope
Stretch

Write setTrafficCustom(bool red, bool yellow, bool green) to show red+yellow together.
