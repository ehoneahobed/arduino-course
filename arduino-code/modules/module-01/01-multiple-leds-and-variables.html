Multiple LEDs & variables

Drive two or three LEDs on different pins from one sketch, using named const int pins instead of magic numbers.

About 35 minutes. Tinkercad primary.

Start here

Learning outcomes

  1. Drive 2–3 LEDs on different digital pins from one sketch.
  2. Use named const int pin variables instead of magic numbers for every LED.
  3. Turn LEDs on and off in a short sequence without copying the wrong pin number.
Concept

One source of truth per wire

Concept

Each digital pin is an independent output. Naming pins with const int redPin = 8; gives you one source of truth per wire. Change the number once when you move a jumper.

const int redPin    = 8;
const int yellowPin = 9;
const int greenPin  = 10;

pinMode(redPin, OUTPUT);
digitalWrite(redPin, HIGH);
Lab

Wire three LEDs

15 min
  1. Create circuit M1-L01-MultiLed.
  2. Place Uno, breadboard, 3 LEDs, 3× 220 Ω resistors.
  3. Wire:
Pin 8  →  220 Ω  →  red LED    →  GND
Pin 9  →  220 Ω  →  yellow LED →  GND
Pin 10 →  220 Ω  →  green LED  →  GND

Configure all three pinMode calls in setup — not in loop.

Code

Traffic sequence

Success: Red on, then yellow, then green, then a short all-off pause, then repeat.

Starter (finish green)

const int redPin = 8, yellowPin = 9, greenPin = 10;
const int stepMs = 1000;

void setup() {
  pinMode(redPin, OUTPUT);
  pinMode(yellowPin, OUTPUT);
  pinMode(greenPin, OUTPUT);
}

void loop() {
  digitalWrite(redPin, HIGH); delay(stepMs); digitalWrite(redPin, LOW);
  digitalWrite(yellowPin, HIGH); delay(stepMs); digitalWrite(yellowPin, LOW);
  // TODO: green on, delay, green off
  delay(stepMs);
}

Complete

const int stepMs = 800, gapMs = 400;
// … pinModes in setup …
void loop() {
  digitalWrite(redPin, HIGH); delay(stepMs); digitalWrite(redPin, LOW);
  digitalWrite(yellowPin, HIGH); delay(stepMs); digitalWrite(yellowPin, LOW);
  digitalWrite(greenPin, HIGH); delay(stepMs); digitalWrite(greenPin, LOW);
  delay(gapMs);
}
Patterns

Named pin constants

Pattern

Named pin constants at the top. One const int per physical wire. Header comments list the wiring.

Check

Check yourself

  1. Why prefer const int redPin = 8; over writing 8 everywhere?
    Model answer

    One place to edit when wiring changes; clearer intent.

  2. Where should the three pinMode(..., OUTPUT) calls live?
  3. You change greenPin to 11 but leave the wire on 10. What happens?
    Model answer

    Green stays dark (or the wrong pin wiggles).

  4. True or false: three LEDs need GND (often one shared rail to Uno GND).
Watch outs

Common mistakes

MistakeFix
Shared resistor for all LEDsOne resistor per LED
Mixed magic numbers and namesUse only named constants
Forgot one pinModeConfigure every output pin
Stretch

Light two LEDs at once for 500 ms (red + yellow), then green alone. Save as M1-L01-Pairs.
