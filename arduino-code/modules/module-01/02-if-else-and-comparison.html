if / else and comparison

Make decisions with if, else if, and else — and write comparisons that say what you mean.

About 35 minutes. Reuse the three-LED circuit from Lesson 1.1.

Start here

Learning outcomes

  1. Branch behavior with if, else if, and else.
  2. Write readable boolean expressions using ==, !=, <, >, &&, and ||.
  3. Drive different LEDs based on a simple mode or counter condition.
Concept

Programs make decisions

Concept

An if checks a condition; else covers otherwise. This is the Decide step in sense → decide → act.

if (mode == 0) {
  digitalWrite(redPin, HIGH);
} else if (mode == 1) {
  digitalWrite(yellowPin, HIGH);
} else {
  digitalWrite(greenPin, HIGH);
}

Critical: == compares; a single = assigns. if (mode = 1) is a legendary bug.

Lab

Mode counter

15 min

Duplicate as M1-L02-IfElse. Cycle mode 0→1→2→0 with only one LED on at a time. Turn all LOW before the if chain.

Complete shape

int mode = 0;
void loop() {
  digitalWrite(redPin, LOW);
  digitalWrite(yellowPin, LOW);
  digitalWrite(greenPin, LOW);
  if (mode == 0) digitalWrite(redPin, HIGH);
  else if (mode == 1) digitalWrite(yellowPin, HIGH);
  else digitalWrite(greenPin, HIGH);
  delay(800);
  mode = mode + 1;
  if (mode > 2) mode = 0;
}
Patterns

Clear conditions

Pattern

Clear conditions over clever ones. Keep modes tiny. Spaghetti if chains become state machines in Module 5.

Check

Check yourself

  1. What is the difference between = and ==?
    Model answer

    = assigns; == compares.

  2. When does the else block run?
    Model answer

    When every preceding if / else if condition was false.

  3. What does (mode == 0) || (mode == 2) mean?
    Model answer

    Mode is 0 or mode is 2.

  4. Why turn all LEDs LOW before the if chain?
    Model answer

    So a previous mode’s LED does not stay lit — known-off baseline.
