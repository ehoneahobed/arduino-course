Reading a button

Sense a pushbutton with digitalRead, prefer INPUT_PULLUP, and light an LED while the button is held.

About 40 minutes. Open Serial before you decide the wiring is wrong.

Start here

Learning outcomes

Open Serial first

This lesson prints button readings — open the Serial Monitor and set baud to 9600 before you decide the wiring is wrong. How-to: How to use the Serial Monitor. Stuck HIGH/LOW? Troubleshooting FAQ.

  1. Use digitalRead to sense a pushbutton.
  2. Wire with INPUT_PULLUP (preferred) and explain HIGH/LOW polarity.
  3. Light an LED while the button is held (momentary control).
Concept

Inputs must be pulled

Concept

An input pin reads voltage. A floating pin can read randomly — pull it. INPUT_PULLUP: pin sits HIGH until the button connects it to GND (active LOW).

int buttonState = digitalRead(buttonPin);  // sense
if (buttonState == LOW) {                  // decide (PULLUP: pressed = LOW)
  digitalWrite(ledPin, HIGH);              // act
}

Lab

Button lights LED

15 min

Circuit M1-L03-Button: LED pin 13 → 220 Ω → GND; button pin 2 ↔ GND. Open Serial Monitor.

Complete

const int buttonPin = 2, ledPin = 13;
void setup() {
  pinMode(buttonPin, INPUT_PULLUP);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}
void loop() {
  int reading = digitalRead(buttonPin);
  if (reading == LOW) {
    digitalWrite(ledPin, HIGH);
    Serial.println("pressed");
  } else {
    digitalWrite(ledPin, LOW);
    Serial.println("released");
  }
  delay(50);
}
Patterns

Document polarity

Pattern

Write // INPUT_PULLUP: pressed == LOW in the header. Debounce and FSMs need that meaning.

Check

Check yourself

  1. What does digitalRead return?
    Model answer

    HIGH or LOW (often printed as 1 / 0).

  2. With INPUT_PULLUP and button to GND, a press reads as?
  3. Why is a floating input bad?
    Model answer

    The pin can randomly read HIGH/LOW without a defined pull.

  4. pinMode(buttonPin, INPUT_PULLUP) belongs in setup.
