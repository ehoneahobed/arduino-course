Build: Washing-machine or lock FSM

Spine build: a timed multi-stage washer or a door-lock FSM — cancel path, alarm, Serial trace. Pick one path. Gate A + Gate B.

About 60 minutes. Draw the diagram before coding.

Start here

Learning outcomes

  1. Build a washing-machine or door-lock FSM with timed stages, cancel, and alarm.
  2. Combine enum + switch, entry/exit, events, and non-blocking millis.
  3. Document state diagram, pins, and timings in the sketch header (Gate B).
Brief

Paths

PathCore states (minimum)
W — WasherIDLE → FILL → WASH → RINSE → DONE (+ ALARM)
L — LockLOCKED → ENTRY → UNLOCKED (+ ALARM on bad code)

Done: operable from LEDs; cancel works mid-cycle; alarm clears on purpose; zero interactive delay; header has diagram.

Wire

M5-L06-Washer or Lock

W: Start→2, Cancel→3; LEDs 8/9/10; buzzer→5. L: Digit A/B→2/3, Enter→4; LEDs locked/unlocked/alarm.

IDLE --START--> FILL --t1--> WASH --t2--> RINSE --t3--> DONE --ACK--> IDLE
  ^               |            |            |
  +---- CANCEL ---+------------+------------+
Long-hold Cancel → ALARM --ACK--> IDLE
Build

Stack the patterns

25 min

Washer shape

// enter FILL/WASH/RINSE: stageStarted = millis(); timeoutArmed = true;
Event ev = collectEvents(now);   // START, CANCEL, TIMEOUT, ACK
handleFsm(ev);
// CANCEL from timed stages → IDLE; long-hold → ALARM
// exit ALARM: buzzer off

Stamp stage durations only in enterState. Document cancel vs fault policy in the header.

Deliverable

Checklist

  • Explicit enum; ≥3 behavioral states beyond on/off
  • At least one timed auto-transition (millis, armed on enter)
  • Cancel/reset to safe idle/locked; alarm with clear way out
  • Serial on every transition; diagram + wiring + timings in header
  • No interactive delay()
Patterns

Stack

Pattern

Diagram in header · enum + handleFsm · enter/exit · events · millis stages. Gate A + Gate B.

Check

Check yourself

  1. Where should stage durations be stamped?
    Model answer

    On state entry (enterState).

  2. What two course gates does this spine satisfy?
    Model answer

    Gate A (non-blocking) and Gate B (explicit FSM + diagram).

  3. You must implement both washer and lock.
  4. Why document cancel vs fault in the header?
    Model answer

    So operators know whether cancel is a safe stop or an alarm.
