Vertical slice

A vertical slice is a thin cut through the whole stack. Ship one happy path first — display polish and extra modes wait.

About 60–90 minutes. Desk hardware required; ESP32 for Capstone C.

Start here

Learning outcomes

  1. Ship one sensing → decision → actuation path end-to-end on real hardware.
  2. Keep the slice aligned to your 9.1 diagram (only needed states/arrows).
  3. Resist feature creep until the slice works.
Concept

Thin cut, not layer cake

Concept

Real input → real decision → real output. Opposite of building all sensors, then all states, then all outputs. “Done” for 9.2 is one happy path demo, not the full rubric.

Part

Pick the slice

CapstoneShip this first
A PlantSoil/light → below threshold → REMIND LED
B GuardianArm → trip → ALARM buzzer/LED
C WeatherSensor → Wi‑Fi ONLINE → one telemetry publish
D ReactionGO → button ISR → reaction ms on Serial
E PointerOne pot → map → one servo with soft limits

Build order: FSM skeleton (enum + enterState) → wire one input → decision → one output → Serial state names. Gate A from minute one — millis, no interactive delay.

Lab

One happy path

45+ min

Implement only the chosen story’s arrows. Definition of done: physical upload; sensor changes cause a visible/audible/networked output; Serial shows state transitions matching the diagram subset; no long interactive delay.

Patterns

Slice plan

Pattern

One story from 9.1. FSM skeleton first. Serial as temporary UX. OLED/MQTT wrap the same values later.

Check

Check yourself

  1. What is a vertical slice in one sentence?
    Model answer

    A thin end-to-end path: real input → decision → real output.

  2. What waits until after the slice works?
    Model answer

    Display polish, extra modes, networking extras / second sensors.

  3. Name two items in the 9.2 definition of done.
    Model answer

    Any two: physical upload, visible actuation from sensor, Serial states, no interactive delay.

  4. Lesson 9.2 requires the full rubric score before moving on.
