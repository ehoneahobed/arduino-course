Demo & retrospective

A demo is evidence, not theater. Inventory patterns you actually used. Package so a reviewer can open the folder and Verify.

About 45–60 minutes plus leftover polish. Course close.

Start here

Learning outcomes

  1. Record a short demo (video/GIF/photos) that proves MVP stories on hardware.
  2. Complete a pattern retrospective (debounce, FSM, non-blocking, ISR, and/or net).
  3. Package the sketch folder: README, diagram, modules, secrets example, checklists.
Concept

Evidence and honesty

Concept

Show sensing → decision → actuation, one resilience moment, and where the diagram lives. Retrospective names patterns you actually used — honesty beats buzzword stuffing.

Part

60–90 s demo script

  1. Name capstone letter + board
  2. Point to wiring / SAFE idle
  3. Run MVP happy path
  4. Show one resilience moment (mash / timeout / offline)
  5. Flash Serial or OLED state names
  6. Open README diagram on camera ~3 s
Part

Hand-in tree

M9-Capstone-<Letter>-<ShortName>/
  README.md
  <MainSketch>.ino
  ButtonDebounce.h / .cpp   (or src/…)
  secrets.h.example         (IoT)
  .gitignore
  media/demo.mp4 | wiring.jpg

README: letter, board, stories, I/O, diagram, build notes, demo link, pattern inventory table, rubric self-score. Ship secrets.h.example — never real passwords.

Lab

Ship the package

30 min

Record demo; fill pattern retrospective (tick only what exists); Verify one last time; zip/folder for review. Optional: half-page “next appliance” plan.

Course close

When 9.5 is done, you have completed the Arduino Coding project spine: one polished capstone using patterns from Modules 0–8. You are ready to build your own appliances beyond the syllabus.

Patterns

Demo script + inventory

Pattern

Rehearse before recording. One inventory row per pattern with “where in code.” Predictable hand-in tree. Secrets stay out.

Check

Check yourself

  1. What four things should a Module 9 demo show?
    Model answer

    Identity/wiring, happy path, one resilience moment, diagram evidence.

  2. Why inventory patterns you did not use as well?
    Model answer

    Honesty for reviewers — proves you know the difference; avoids fake claims.

  3. What file replaces real Wi‑Fi passwords in the hand-in?
    Model answer

    secrets.h.example.

  4. Module 9 credit allows a Tinkercad share link instead of hardware media.
