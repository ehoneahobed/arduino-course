When to use a library

A library is reusable device code. You #include, create an object, attach/begin, and call a documented API — then ship features instead of reinventing pulse trains.

About 40 minutes. Servo smoke-test; DHT waits for hardware.

Start here

Learning outcomes

  1. Explain when a library beats writing low-level timing or protocol code yourself.
  2. Include a library and call a documented API (attach, write, …).
  3. Contrast [TC†] library limits with [HW] Library Manager installs.
Concept

Ship features, not every microsecond

Concept

For DHT checksums, I²C displays, and servo pulses, a maintained library is almost always correct at beginner–intermediate level. You trade full control for working devices.

[TC†] honesty

Tinkercad’s catalog is small — Servo is the reliable star. DHT / many OLED helpers may be absent. Learn the #include + API habit here; install real libs on hardware for 4.2–4.3.

Anatomy

#include <Servo.h>     // 1. bring API in
Servo needle;          // 2. object

void loop()  { needle.write(90); }

[HW]: Sketch → Include Library → Manage Libraries → install → open Examples → change only pins. Prefer Library Manager over random GitHub zips.

Lab

Servo smoke-test

15 min

Circuit M4-L01-LibraryIntro: Uno + Servo, signal→9, VCC→5V, GND→GND. Confirm you can say: “I included Servo, attached 9, called write.”

Complete shape

#include <Servo.h>
Servo demoServo;
const int servoPin = 9;
void setup() {
  demoServo.attach(servoPin);
  Serial.begin(9600);
}
void loop() {
  demoServo.write(90); delay(800);
  demoServo.write(0);  delay(800);
  demoServo.write(180); delay(800);
}

delay is OK for this one-device smoke-test. Spine builds return to millis.

Patterns

Documented API over bit-banging

Pattern

Prefer myServo.write(90) to hand-rolled pulses. Read the Example first. Wrap library calls in thin project helpers (pointNeedle(angle)) so you can swap libraries later.

Check

Check yourself

  1. What does #include <Servo.h> do?
    Model answer

    Pulls in the library’s declarations so you can use Servo and its methods.

  2. Why prefer a library for DHT-style sensors at first?
    Model answer

    Precise timing/checksums — maintained libraries are faster and less error-prone.

  3. Every IDE Library Manager library also exists in Tinkercad.
  4. Where should you look first after installing a library?
    Model answer

    The Examples that ship with it (plus README/docs).
