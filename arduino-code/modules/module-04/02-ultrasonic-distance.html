Ultrasonic distance

Ping TRIG, measure ECHO with pulseIn, convert µs → cm, then reject timeouts and absurd values before any alarm.

About 45 minutes. Hardware preferred — sim timing is idealized.

Start here

Learning outcomes

  1. Explain HC-SR04-style trigger / echo distance at a practical level.
  2. Measure with pulseIn, convert to centimeters, print on Serial.
  3. Handle out-of-range / timeout readings so garbage does not drive actuators.
Concept

Pulse-echo

Concept

Distance ≈ (travel time × speed of sound) / 2. Pulse TRIG HIGH ~10 µs, then pulseIn(ECHO, HIGH) for echo width in microseconds. Bad readings (no echo, soft targets) are the real lesson.

PinRole
TRIGOutput — start a ping
ECHOInput — pulse width ∝ distance
VCC / GND5 V and ground (classic HC-SR04)
Part

µs → cm and timeouts

unsigned long us = pulseIn(echoPin, HIGH, 30000UL); // 30 ms timeout
if (us == 0) return -1;           // invalid
float cm = us / 58.0;             // approx at room temp
if (cm <= 0 || cm > maxCm) return -1;

pulseIn blocks until the pulse ends or timeout — keep timeouts bounded. Pace pings (~5–20 Hz); do not hammer every microsecond.

Lab

Read and validate

18 min

Circuit M4-L02-Ultrasonic: TRIG→7, ECHO→6. Open Serial. Prefer [HW]; in [TC†] move the distance control if present.

Complete shape

float readDistanceCm() {
  digitalWrite(trigPin, LOW);  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH); delayMicroseconds(10);
  digitalWrite(trigPin, LOW);
  unsigned long us = pulseIn(echoPin, HIGH, 30000UL);
  if (us == 0) return -1.0;
  float cm = us / 58.0;
  if (cm <= 0 || cm > maxCm) return -1.0;
  return cm;
}

Print OK + cm, or OUT when invalid. Sentinel -1 beats pretending “0 cm”.

Patterns

Measure → convert → validate

Pattern

Never feed raw pulseIn into an alarm. Wrap ranging in float readDistanceCm() that returns a value or -1. Code validation even if the sim looks perfect.

Check

Check yourself

  1. Why divide by roughly two (or use / 58)?
    Model answer

    Sound travels to the target and back — you want one-way distance.

  2. What does pulseIn returning 0 usually mean with a timeout?
    Model answer

    Timeout / no echo — treat as invalid.

  3. Why return -1 instead of 0 cm for errors?
    Model answer

    0 cm could mean “touching”; a sentinel is clearer.

  4. Tinkercad alone is enough to trust parking thresholds forever.
