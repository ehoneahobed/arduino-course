Servo positioning

Drive an SG90-style servo with Servo: prove sweep, then map a potentiometer to roughly 0–180°.

About 40 minutes. One of the best Module 4 labs fully in Tinkercad.

Start here

Learning outcomes

  1. Drive a servo with attach and write(angle).
  2. Sweep for a motion test, then map pot 0–1023 → ~0–180°.
  3. Pace motion updates so you are not commanding thousands of times per second without need.
Concept

Angle, not PWM duty

Concept

A hobby servo holds an angle (~0–180°). The Servo library generates the control pulse. Signal→9, VCC→5V, GND→GND. Pot: 5V — wiper→A0 — GND.

Part

Sweep, then map

int raw = analogRead(A0);
int angle = constrain(map(raw, 0, 1023, 0, 180), 0, 180);
arm.write(angle);

If the horn buzzes at an endpoint on hardware, shrink the map (e.g. 10–170). Optional: only write when the angle changes.

Lab

Pot → horn

15 min

Circuit M4-L04-Servo: Uno + Servo on 9 + pot on A0. Success: turning the pot moves the horn smoothly.

Complete shape

arm.attach(servoPin);
int angle = constrain(map(analogRead(potPin), 0, 1023, 0, 180), 0, 180);
if (angle != lastAngle) { arm.write(angle); lastAngle = angle; }
Patterns

Calibrate with sweep, then map

Pattern

Prove write(0/90/180) before closed-loop control. Soft-clamp with constrain. In interactive builds, update the target angle each loop — save long blocking sweeps for demos.

Check

Check yourself

  1. Which library type drives the servo here?
    Model answer

    #include <Servo.h> and a Servo object.

  2. What does map(raw, 0, 1023, 0, 180) give when raw is 512?
    Model answer

    About 90 degrees.

  3. Why might you shrink 0–180 to 10–170 on hardware?
    Model answer

    To avoid endpoint buzz / mechanical limits.

  4. This lesson is intended primarily for Tinkercad.
