Build: Parking assist or climate alert

Spine build: sense distance or temperature, classify OK / WARN / ALERT, drive LEDs (optional buzzer). Serial is the UI. Pick one path.

About 60 minutes. Gate A: no long interactive delay.

Start here

Learning outcomes

  1. Build a parking assist (distance) or climate alert (temp) with LED/buzzer levels.
  2. Combine library or pulse sensing, functions, optional structs, and non-blocking timing.
  3. Document wiring, thresholds, and TC†/HW limits for retuning.
Brief

Paths

PathSenseAlert idea
P — ParkingDistance cmFar = green; mid = yellow; near = red + optional beep
C — ClimateTemp °CCool = green; warm = yellow; hot = red + optional beep

Done: moving the target / pot changes levels cleanly; Serial alone demos; header lists pins and thresholds; invalid → FAULT, not ALERT.

Wire

M4-L06-EnvironmentMeter

P: TRIG→7, ECHO→6. C: DHT DATA→2 or pot A0. LEDs G/Y/R on 8/9/10 (+220 Ω); optional buzzer→5.

enum AlertLevel { LEVEL_OK, LEVEL_WARN, LEVEL_ALERT, LEVEL_FAULT };
// Parking (nearer = worse) — tune from YOUR Serial:
const float warnBelow  = 80.0;
const float alertBelow = 30.0;
// Climate (hotter = worse):
const float warnAbove  = 28.0;
const float alertAbove = 32.0;
Build

Logic shape (Path P)

25 min

Sample · classify · LEDs · millis

if (now - prevSample >= sampleInterval) {
  prevSample = now;
  lastCm = readDistanceCm();          // -1 → FAULT
  level = classifyDistance(lastCm);   // alert / warn / ok
  setLevelLeds(level);                // one clear indication
}
serviceBuzzer(level, now);            // one-shot chirp on ALERT
// paced Serial: cm + level name

Path C: same LED helpers; sample DHT every ~2 s (or pot stand-in 15–35 °C). Invalid / nan → FAULT LEDs, never scream ALERT.

Deliverable

Checklist

  • Millis-paced samples (ultrasonic ~100–200 ms; DHT ~2000 ms)
  • At least 3 levels with named thresholds at the top
  • 2–3 LEDs show the level; Serial prints reading + level
  • Invalid readings → safe/FAULT — not ALERT
  • Header documents pins, thresholds, TC†/HW path
Patterns

Stack

Pattern

Sensor function (+ optional packet) · validate · named thresholds · setLevelLeds · millis for sample/print/chirp. Gate A still applies.

Check

Check yourself

  1. Why must invalid readings not map to ALERT?
    Model answer

    Timeouts / NaN would false-alarm constantly.

  2. Which Module 2 rule still applies?
    Model answer

    No long blocking delay() on the interactive path — pace with millis.

  3. You must complete both parking and climate paths.
  4. Where should threshold constants live?
    Model answer

    Named constants at the top of the sketch — easy to tune from Serial.
