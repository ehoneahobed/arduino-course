Structs for sensor packets

Bundle related fields — value, unit, timestamp, valid — into one typed packet you can print, pass, and alert from.

About 40 minutes. Pure language skill; pot stand-in is enough.

Start here

Learning outcomes

  1. Define a C++ struct that bundles sensor fields.
  2. Fill and print packets consistently so Serial looks like a tiny UI.
  3. Pass structs into helpers to keep loop readable for the spine build.
Concept

One packet, not three globals

Concept

A struct groups related variables under one type. Carry the reading, its unit label, millis() when sampled, and whether it is trustworthy.

struct SensorPacket {
  float value;
  const char* unit;       // "cm", "C", "%"
  unsigned long timestamp;
  bool valid;
};
Part

Fill and print

SensorPacket readFakeDistance() {
  SensorPacket p;
  p.timestamp = millis();
  p.unit = "cm";
  int raw = analogRead(A0);
  if (raw < 15) { p.valid = false; return p; }
  p.value = map(raw, 15, 1023, 5, 150);
  p.valid = true;
  return p;
}
void printPacket(const SensorPacket& p) {
  Serial.print(p.timestamp); Serial.print('\t');
  if (!p.valid) { Serial.println("INVALID\t---"); return; }
  Serial.print(p.value, 1); Serial.print('\t'); Serial.println(p.unit);
}

Pass const SensorPacket& — read-only, no copy. Separate ClimatePacket when fields differ.

Lab

Fake distance packets

15 min

Circuit M4-L05-Structs: Uno + pot on A0. Headers: ms  value  unit. Mark valid = false for a fault demo (e.g. raw < 15).

Patterns

Sensor packet

Pattern

Fill in read…(); print in printPacket; decide alerts from fields — not scavenger-hunted globals. Stable Serial columns → future OLED/MQTT (Modules 6–8).

Check

Check yourself

  1. What problem do structs solve vs three unrelated globals?
    Model answer

    They bundle related fields into one typed value you can pass and print together.

  2. Why include a valid flag?
    Model answer

    So callers know whether value is trustworthy.

  3. What does timestamp usually store?
    Model answer

    Typically millis() when the sample was taken.

  4. You need a DHT sensor to practice structs.
