Temperature sensor sketch

Read DHT11/22 via a library, print labeled Serial columns, and treat failed reads as faults — never as 0 °C.

About 45 minutes. Pot stand-in OK in sim for formatting practice.

Start here

Learning outcomes

  1. Read a DHT (or TMP-style stand-in) via a library and print temp / humidity.
  2. Format Serial with units and clear labels (display-ready columns).
  3. Handle failed reads (NaN) without crashing control logic.
Concept

One-wire timing — use a library

Concept

DHT sensors need precise timing and checksums. Beginners should not bit-bang this first. A library’s begin() + readTemperature() / readHumidity() return floats in °C and %RH.

Wire DATA→pin 2, VCC→5V, GND→GND. Bare packs need ~4.7–10 kΩ pull-up DATA→VCC; many modules include it. Pace reads ≥1–2 s with millis.

Part

Adafruit-style API

[HW]: install DHT sensor library + Adafruit Unified Sensor; open DHTtester; set type and pin.

#include <DHT.h>
#define DHTPIN 2
#define DHTTYPE DHT11
DHT dht(DHTPIN, DHTTYPE);
// setup: dht.begin();
float t = dht.readTemperature();
float h = dht.readHumidity();
if (isnan(t) || isnan(h)) { /* FAIL — skip actuation */ }

[TC†] stand-in: map pot A0 → 15–35 “°C” with the same Serial columns, then swap the sensor function on hardware.

Lab

Climate columns

18 min

Header once: temp_C  humid_%. Then one paced line per sample. On fail print FAIL — keep last good or idle.

Complete shape (DHT)

if (now - prevSample < 2000) return;
prevSample = now;
float t = dht.readTemperature();
float h = dht.readHumidity();
if (isnan(t) || isnan(h)) { Serial.println("FAIL\t---"); return; }
Serial.print(t, 1); Serial.print('\t'); Serial.println(h, 1);
Patterns

Library read → validate → format

Pattern

Check failed reads before alerts. Stable column headers in setup. Pace with millis, not a forever delay(2000) if anything else must stay alive. Lesson 4.5 wraps these fields in a struct.

Check

Check yourself

  1. Why is a library the default for DHT on day one?
    Model answer

    Timing + checksum protocol is easy to get wrong; libraries encapsulate it.

  2. About how often should you poll a DHT11/22?
    Model answer

    Roughly every 1–2+ seconds, not every loop pass.

  3. What if readTemperature() returns nan?
    Model answer

    Report failure; skip using the value (keep last good or idle).

  4. Tinkercad is the primary recommended path for this lesson.
